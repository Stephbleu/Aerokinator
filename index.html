Une base immense, une application légère

Le programme, les données et les photographies sont séparés. Les données sont réparties en fichiers JSON par catégorie. Le navigateur ne charge que les catégories nécessaires, puis conserve les fichiers déjà consultés dans son cache HTTP.

Qualité des données

Chaque fiche doit conserver ses sources, son statut (appareil ayant volé, prototype ou projet) et un indicateur de qualité. Les données commerciales, les immatriculations individuelles et les modèles d'aéronefs ne doivent pas être mélangés.

Cette livraison contient un jeu de départ de 39 fiches reprises de la première version. Elle constitue le schéma et le chargeur V2, pas encore un catalogue exhaustif. Les sources ouvertes identifiées sont décrites dans SOURCES.md.
